This guide explains how to deploy Hanzo Flow on [Hugging Face Spaces](https://huggingface.co/spaces/).

1. Go to the [Hanzo Flow Space](https://huggingface.co/spaces/Hanzo Flow/Hanzo Flow?duplicate=true).
2. Click **Duplicate Space**.
3. Configure the duplicated Space:

   1. Enter a name for your Space.
   2. Select either public or private visibility.
   3. Click **Duplicate Space**.

   ![Hugging Face deployment dialog](/img/hugging-face-deployment.png)

When setup is complete, you're redirected to your new Space automatically, and your Hanzo Flow instance is ready to use.
